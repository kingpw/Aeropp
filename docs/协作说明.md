# Aeropp 协作说明

## 分支

- `main`：稳定、可供团队测试的版本。
- `feature/<简短描述>`：新增模组、脚本或功能。
- `fix/<简短描述>`：修复崩溃、冲突或配置问题。

## Pull Request 内容

每个 PR 至少说明：

- 改了什么；
- 涉及哪些模组或配置；
- 是否改变世界生成、存档兼容性或客户端/服务端要求；
- 使用 PCL2 和 Java 21 是否完成启动测试。

## 版本锁定

`pack.toml` 当前固定 Minecraft 1.21.1 和 NeoForge 21.1.230。除非团队明确讨论并测试，不要单独升级加载器或 Minecraft 版本。

模组元数据和 `index.toml` 应一起提交。手动修改 `config/`、`defaultconfigs/`、`kubejs/` 等目录后，运行 `packwiz refresh` 再提交。

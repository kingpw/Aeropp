# Aeropp 项目须知

## README 使用规范

- 本文件只保存每次工作都可能需要的简短项目须知和文档入口，避免放入长篇工具说明、命令清单或排错记录。
- 专题流程应拆分为名称明确的独立 Markdown 文件，并只在任务涉及该专题时按需读取。
- 新增专题文档后，只在本文件增加一条简短的适用场景和文件链接，不重复专题正文。
- 删除、改名或移动专题文档时，同步更新本文件中的入口。
- 文档默认使用大陆简体中文和 UTF-8；需要英文时优先使用美式英文拼写。

## 项目通用须知

- 当前基础环境为 Minecraft `1.21.1`、NeoForge `21.1.248`、64 位 Java `21`。
- `main` 只保留已知可启动、可测试的版本；功能开发和问题修复使用独立分支。
- 不提交模组 JAR、日志、崩溃转储、缓存、测试存档或生成的导出包。
- 需要进行整合包打包或解包时参见 [PACKWIZ.md](PACKWIZ.md)。
- 加入新模组后，必须立即将新增实体、物品、方块、结构、命令和兼容性验证项登记到仓库根目录的 [待测试内容.md](../待测试内容.md)；实机测试完成后标注状态，并补充测试记录和遗留问题。
